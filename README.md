# My Portfolio

A modern, interactive portfolio website built with React, Vite, and Tailwind CSS. It features smooth scrolling, complex animations, and fluid background effects.

## Technologies Used
- **Framework**: React 19, Vite
- **Styling**: Tailwind CSS
- **Animations & Interaction**: Framer Motion, GSAP, `@studio-freight/lenis` (smooth scroll)
- **Effects**: `webgl-fluid`
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone this repository (if applicable).
2. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

To run the application on your local machine:

```bash
npm run dev
```

To expose the application to your local network (so you can test it on your phone or other devices):

```bash
npm run dev -- --host
```
The server will start and provide you with a `localhost` URL and a `Network` IP address.

### Building for Production

To create a production-ready build:

```bash
npm run build
```
The built files will be located in the `dist` directory.

To preview the production build locally:
```bash
npm run preview
```
